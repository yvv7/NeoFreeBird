## What's New & Key Highlights

* **Modernized Settings UI**:
  * Clean iOS Inset Grouped card design with adaptive backgrounds for Light, Dim (`#1E2732`), and True Dark (`#16181C`).
  * Vibrant squircle category badges with centered vector icons.
  * Real-time **Settings Search** (`UISearchController`) to quickly find and toggle any preference across all sections.
  * Switches automatically tint to your chosen Twitter theme accent color with tactile haptic feedback.
* **Shared Sequential Download Engine**:
  * Download multiple videos across different tweets smoothly with a centralized queue.
  * Real-time `"Downloading X of Y"` tracking without FFmpeg collisions or overlapping progress bars.
* **Frosted Glass Floating HUDs**:
  * **Dynamic Progress Pill (`NFBProgressPill`)**: Shows live progress percentages and file counts with spring animations.
  * **Snappy Toast Alerts (`NFBToast`)**: Compact, fast confirmation HUDs that automatically clean up upon completion.
* **Media Downloads**:
  * Download videos in MP4 (including highest quality auto-detection) or HLS streams.
  * Direct audio-only (`.m4a`) and GIF downloads.
  * Direct saving to Camera Roll, the Files app, or iOS Share Sheet.
* **Feed & Timeline Clean-Up**:
  * Block promoted ads, timeline prompts, and "Who to follow" suggestions.
  * Hide premium "Get Verified" / "Upgrade" nag prompts.
  * Disable video auto-play, captions overlay, and RTL text alignment.
* **Customization & Branding**:
  * Bring back classic Twitter bird branding, custom app icons, and tab bar theming.
  * Custom font selection for regular and bold typography.
  * Country and keyword filter options.

# Compiling NeoFreeBird-BHTwitter

## Using GitHub Actions (Easiest)

1. Fork this repository to your GitHub account.
2. Go to the **Actions** tab in your repository and click **"I understand my workflows, go ahead and enable them"**.
3. Go to **Settings** → **Actions** → **General** → **Workflow permissions**, select **"Read and write permissions"**, and click **Save**.
4. Return to the **Actions** tab and select **"Build Tweak"** from the left sidebar.
5. Click **"Run workflow"** and provide:
   - **Deployment format**: `sideloaded`, `trollstore`, or `rootless`.
   - **Decrypted IPA URL**: Direct download link to a decrypted Twitter/X IPA.
6. Once the build finishes, download your ready-to-install `.ipa` / `.deb` from the **Artifacts** section at the bottom of the workflow run.

## Compiling Locally

### Prerequisites

1. Install [Theos](https://github.com/theos/theos).
   > **Note for Linux users**: The toolchain that ships with Theos may be outdated. Download the latest toolchain for your distro from [here](https://github.com/L1ghtmann/swift-toolchain-linux/releases/latest) and replace `$THEOS/toolchain/linux` with its contents.
2. Install [cyan](https://github.com/asdfzxcvbn/pyzule-rw) if you want sideload or TrollStore builds:
   ```bash
   pip install https://github.com/asdfzxcvbn/pyzule-rw/archive/main.zip
   ```
3. Clone this repository recursively:
   ```bash
   git clone --recursive https://github.com/orionblur/NeoFreeBird.git
   cd NeoFreeBird
   ```
4. Make the build script executable:
   ```bash
   chmod +x ./build.sh
   ```

### Build Commands

```bash
./build.sh [OPTIONS]
```

* **Sideloading (`.ipa`)**:
  Place your decrypted IPA in `packages/com.atebits.Tweetie2.ipa` and run:
  ```bash
  ./build.sh --sideloaded
  ```
* **TrollStore (`.tipa`)**:
  ```bash
  ./build.sh --trollstore
  ```
* **Rootless Jailbreak (`.deb`)**:
  ```bash
  ./build.sh --rootless
  ```
* **Rootful Jailbreak (`.deb`)**:
  ```bash
  ./build.sh --rootfull
  ```

# Rebranding

`rebrand.sh` applies custom display names and icon branding to an IPA.

Resource packs work on both macOS and Linux via [scar](https://github.com/theacrat/scar) and [resvg](https://github.com/linebender/resvg). Both are downloaded automatically if they aren't in `PATH`.

```bash
./rebrand.sh [-t | --twitter-branding] [--resource-pack ZIP] [-o OUTPUT] IPA
```

Options:
* `-t, --twitter-branding`: sets the app's display name to Twitter.
* `--resource-pack ZIP`: applies a theme pack `.zip`.

Example:
```bash
./rebrand.sh -t --resource-pack theme.zip -o packages/Twitter-rebranded.ipa packages/NeoFreeBird-sideloaded.ipa
```
